# Preview

`preview.png` is composed from real screenshots of the WLAN Monitor 0.5.0 panel on the author's home network (Omarchy shell, empty workspace): the Devices page grouped by platform (with NordVPN connected, so the new VPN line is visible), the Network map grouped by Wi-Fi band, and a device's details opened from the map. Only the panel was cropped from the screen; no other desktop content is included.

For the screenshots the owner's first name was removed from three device names (e.g. "iPad Pro Uwe" is shown as "iPad Pro") by a temporary, display-only filter in the collector, and the grouping was set for the shots. Both were undone afterwards. No FRITZ!Box user name or password is visible.

Layout, colours, icons, device types, groups, speeds and signal are the plugin as it renders. The page around the panels is a small HTML composite rendered with headless Chromium.
